# Opera Theme Installation Instructions

## MilkOutside Opera Theme

### Installation Steps:

1. **Open Opera Extensions**
   - Open Opera browser
   - Navigate to `opera://extensions/`
   - Enable "Developer mode" (toggle switch in top left)

2. **Load Theme Extension**
   - Click "Load unpacked" button
   - Navigate to and select `extras/opera` directory from milkoutside.nvim
   - The theme will be loaded as an extension

3. **Activate Theme**
   - The theme will activate automatically when loaded
   - You can toggle it using the extension icon in the toolbar
   - Click the icon to enable/disable the theme

### Features:

- **Dark theme** with MilkOutside color palette
- **Custom toolbar** and tab styling
- **Themed URL bar** and buttons
- **Matching bookmarks** and history panels
- **Custom scrollbars** and selection colors
- **Toggle functionality** - enable/disable via extension icon
- **Popup interface** for theme control

### Usage:

- **Enable Theme**: Click the MilkOutside icon in Opera toolbar, then click "Enable Theme"
- **Disable Theme**: Click the MilkOutside icon, then click "Disable Theme"
- **Status Check**: The popup shows current theme status

### Alternative Installation:

You can drag the entire `extras/opera` folder directly onto the `opera://extensions/` page when Developer mode is enabled.

### Removal:

To remove the theme:
1. Go to `opera://extensions/`
2. Find "MilkOutside Theme" in the list
3. Click "Remove" or the trash icon

### Troubleshooting:

- If the theme doesn't appear, restart Opera
- Make sure Developer mode is enabled
- Check for any extension errors in opera://extensions/
- Some websites may override theme colors with their own styles
- Theme toggle functionality requires the extension to be enabled

### Notes:

- This theme uses Opera's extension theming API
- Works with Opera 70+ versions
- Theme settings are stored locally and persist across restarts
- The extension includes both automatic and manual theme control options
